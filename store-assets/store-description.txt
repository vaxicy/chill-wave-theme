Chill Wave gives Chrome a calm violet tide: a soft lilac frame around the window and tabs, an almost-white toolbar, bookmark bar and new tab page, and one deep-blue accent for links and headings. Every layer is a single flat colour — no wallpaper, no gradients — and the text tones are tuned so tab titles, bookmarks and the address bar stay easy to read. Incognito windows keep a slightly deeper violet frame so private windows stay visually distinct.
